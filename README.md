# AskRivo — Mortgage Friend

AskRivo is a deterministic mortgage assistant demo for the UAE.
All numeric outputs are computed by a server-side calculator; the AI only formats language.

## Run locally
1. Copy `.env.local` values (OpenRouter key + INTERNAL_API_KEY).
2. `npm install`
3. `npm run dev`

## Deploy
This repo is configured for Vercel. Add environment variables in the Vercel project settings before deploying.
